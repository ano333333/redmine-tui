# e2e

このファイルのスコープは `tests/e2e/` です。

- シナリオはテスト関数ごとに固定し、`// Scenario:`、`// Given`、`// When`、`// Then` をコメントで書いてください。
- シナリオ固有のデータは、GivenでRedmine APIを使って追加してください。他の利用者による更新や競合も、APIによる更新として書いてください。
- 結果は画面表示と、Redmine APIで取得し直した状態で確認してください。リクエスト回数は確認しないでください。
- editorは `VISUAL` に指定した `FakeEditor` で置き換えてください。
